# Calculator

This project is a part of [The Odin Project course](https://www.theodinproject.com)

You can check out my project **[here](https://antonizarzycki.github.io/odin-calculator/)**

## Limitations

- Only supports one calculation at a time, e.g. "3\*5", typing "5+3\*4" will result in 5 + 3 = 8, 8 \* 4 = 32 (won't respect calculation order). The brackets are only used for negative numbers
